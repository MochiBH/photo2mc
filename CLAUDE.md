# Jungle coach

Single script, `riot_jungle_report.py` (Python 3, standard library only). See README.md.

- Run: `python riot_jungle_report.py "Name#TAG"`; add `--offline` to reuse `data/`.
- Never put a Riot key in code or commits. The script sends `RIOT_API_KEY` if set, otherwise relies on the environment's network secret for `X-Riot-Token`.
- Riot rejects the default Python User-Agent with 403; keep the custom one in `api_get`.
- Zones live in `raw_zone` (blue base bottom-left, river x + y = 14800, top side y > x). The report prints a zone check against real turret and epic-monster positions; keep it at 100% when changing thresholds.
- Timeline frames are one per minute, so "near me" counts are approximate (radius `NEAR`). Voidgrub kills are one event per grub.
- `data/` and `out/` are git-ignored (raw match data includes other players).

## Website (`app/`)

- React 19 + Tailwind 4 + Motion on Vite, deployed on Vercel with Root Directory `app`. Supabase for logins and data. See README "The website".
- `app/src/wm/` holds the Watermelon UI components (adapted, MIT). New UI should reuse them and their motion style (spring pills, blur-in).
- `app/src/fx/` holds the anime.js effects: `backdrop.jsx` (aurora + canvas dot grid; `ripple()` sends a wave through it), `fx.js` (`burst`, `shake`, `rippleFrom`), `text.jsx` (`SplitTitle`, `Scramble`), `ring.jsx` (self-drawing gauge), `draw.js` (`useDrawIn` for `data-draw` strokes and `data-pop` marks). Use these for new showpiece motion; keep Motion for layout and presence. Everything in `fx/` must stay still under `prefers-reduced-motion` (the `calm` flag).
- The design is dark only: tokens in `src/index.css`, lime for actions and wins, melon pink only for deaths, losses and the enemy, cyan and violet as atmosphere. Display type is Unbounded (`font-display`), used for the title, hero numbers and timers only.
- `app/src/session.jsx` owns sign-in, the profile, stats, the sync loop and per-player saved state (`useSynced`). Nothing personal is hard-coded in views; everything comes from `useSession().stats` for the active role.
- Server: `app/api/sync.js` (Vercel function) calls `app/server/sync.mjs`, `riot.mjs` and `analysis.mjs`. `analysis.mjs` is a port of `riot_jungle_report.py`; `scripts/check-analysis.mjs` must keep reporting that it matches. Schema and row-level security are in `app/supabase/schema.sql`.
- Sign-in is by username and password. `app/server/players.mjs` (shared by browser and server) holds the allowed usernames and maps each to a made-up address on a reserved domain; accounts are created by hand in SQL (`app/supabase/add-player.sql`). Never write a player's password into code, tests, docs or commits.
- The server holds no database secret. `api/sync.js` creates a Supabase client with the public key plus the caller's token and does everything as that player under row-level security; it refuses accounts that are not on the player list. The only server secret is `RIOT_API_KEY`. Only `VITE_*` values reach the browser.
- Live project: Supabase `jungle-coach` (ref `xaqqahmfcqfupycwlsxy`, org Forge Quant, free plan). `scripts/check-live.mjs <username>` signs in and runs the real sync end to end.
- Roles: `src/lib/roles.js` (rules, checkpoints), `src/lib/insights.js` (leaks generated from stats), `src/lib/content.js` (course per role), `src/lib/live.js` (build and plan engine for any champion). Nunu and Kha'Zix jungle use the hand-tuned rules in `src/lib/legacy.js`, which is generated by `scripts/extract-legacy.mjs` from `scripts/legacy-page.html`.
- Data in `app/public/data/`: `champ-builds.json` (OP.GG builds per champion and role, item prices), `builds.js` (hand-written champion tags), course files per role.
- Check with a demo build: `node scripts/make-demo.mjs`, `VITE_DEMO=1 npx vite build`, then `node scripts/shot.mjs <tab> [light|dark] [steps file] [jungle|support]`: it must report scrollWidth 400 and no errors. Outside this sandbox Node needs no proxy flags; here use `NODE_USE_ENV_PROXY=1` for scripts that call Riot.
- The Claude artifact (claude.ai/artifact/XsM979nCJb4bf5qgbkRqyW) is the older single-player version with the coach chat; this code no longer builds it.
